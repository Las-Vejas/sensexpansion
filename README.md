# sensexpansion

This is an expansion module for the [Hackxpansion console](https://github.com/hackclub/hackxpansion). This module provides the console with different information like temperature, humidity, rotation, and others.
The module consists of the **BME280** temperature and humidity sensor and the **LIS3DH** accelerometer.
